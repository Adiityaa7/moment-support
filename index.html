Moment support

A wrist nudge when an app visit passes the limit you chose.

iPhone + Apple Watch · Offline evaluation version 0.7.2 · Updated 20 October 2026

Private offline trial

Moment 0.7.2 is intended for invited internal TestFlight testers. It is not a public App Store release. It offers optional system alarms on iOS 26+, plus the earlier paired-device local notification mode. No reminder host, push-service account, or subscription is needed.

Automatic watch delivery is experimental. Exact 15-second alerts and immediate stopping after exit are not guaranteed. Physical-device verification is still needed.

A simpler iPhone interface

Moment now uses white screens, standard iOS grouped lists, system text, and blue controls. The Apps tab shows your limits and task; Nudges holds reminder settings, with longer explanations on detail pages.

Permissions at first launch

Open Moment on each device to see its setup guide. On iPhone, Continue shows Apple’s Alarms prompt (iOS 26+) and then optional phone notification permission. On watch, the guide offers separate local notification permission. You can skip any permission or choose Set up later. Once finished or skipped, the guide does not appear on every launch. Reopen it on iPhone in Setup → Permissions.

Granting permission does not enable a reminder mode. Choose one in Nudges, then connect your apps in Shortcuts. System alarms do not require ordinary phone or local watch notification permission. If a permission was denied, change it later in Settings.

System alarm mode

In Moment → Nudges, choose Use system alarms and allow Alarms. First try Test an alarm in 8 seconds, return to the watch face, and check which device alerts. The system can alert with Moment closed. It may sound on iPhone and override silent mode and Focus. There is no 15-second cutoff. Apple controls the vibration and duration; custom watch presets do not apply.

The app-close automation requests cancellation on iPhone. Use the system alarm Stop button if cancellation is late or missing. Stop all alarms & pause reminders on iPhone also pauses future visits; unpause on Apps before the next test. System alarm mode replaces automatic Moment phone/watch notifications for new visits. Open both updated apps once before switching modes. Keep Moment visible and do not require Face ID to launch it: Apple documents that hidden or launch-locked apps cannot use AlarmKit. Paired-watch delivery remains unverified on real hardware.

Set up Instagram and YouTube

Both rules start enabled at 15 seconds. Your existing choices survive updates. First-time setup needs four Shortcuts automations: an open and a close for each app. The Setup screen shows the events Moment has actually received. Existing Start/End app session automations continue to work; do not duplicate them.

  1. Install the invited build on iPhone. In TestFlight, open Moment → Information → App Details and install the compatible Apple Watch app if needed. Open both apps and follow or skip their permission guides. For single-notification mode, allow local wrist alerts on watch. Moment has no account or sign-in step.
  2. Tap Test a local alert on watch, return to the watch face, and keep iPhone unlocked. Check for an alert after eight seconds. This tests a locally scheduled alert, not app detection.
  3. For single-notification mode, open Moment → Nudges, turn off system alarms and enable Send reminders to paired watch, and choose a next task and foreground rhythm in Custom rhythms & first-step exercise. After upgrading, open both apps once to clear repeat requests from older builds.
  4. In Shortcuts, create App → Is Opened for Instagram. Add Moment's Start Instagram timer action and choose Run Immediately. No rule picker is needed.
  5. Create App → Is Closed for Instagram, using Stop Instagram timer, also Run Immediately. Repeat both for YouTube using Start YouTube timer and Stop YouTube timer. Custom app rules still use the generic Start/End app session actions with the matching rule.
  6. Stay in that app past its limit with Moment closed on watch. On a new visit, leave before the limit. Record whether you felt an alert and whether cancellation arrived in time.

If no wrist alert arrives

Check both automations, watch notification permission, Focus, haptic settings, pairing, and Bluetooth/local connectivity. Open Moment on both devices once after installation. A watch scheduling receipt confirms scheduled requests, not that a notification appeared or was felt. Opening updates that arrive over 10 seconds late or past their first deadline are skipped.

Single-notification mode

Single-notification mode requests one standard watch notification at your limit. There are no repeat alerts for that visit. A close update must reach the watch to cancel a pending reminder; a delayed update can mean an alert after exit. Use Stop this visit directly on watch to cancel locally. Stop on iPhone also sends cancellation, but transfer can be delayed. Pause offers a separate five-minute break.

Return to your task

Choose a small next step on the Apps screen. Tap Return to my task in the watch notification to open Moment and start your selected foreground rhythm. If an exercise is already unfinished, it is preserved.

The new Persistent preset requests a click once per second within a 15-second window. Tap Stop haptics to end early. Losing watch-app activity stops custom taps without automatically resuming. Other foreground patterns and Visual only remain available.

Automatic custom vibration for 15 seconds with Moment closed is not supported. Background notifications use Apple's standard vibration, whose timing and duration Moment cannot control. The extended cue requires Moment active on watch. The optional system alarm mode is separate: it can run with Moment closed, but has no app-enforced cutoff and does not use custom presets.

For stronger standard alerts, choose Watch Settings → Sounds & Haptics → Haptics → Prominent. This watch-wide setting adds a tap before some alerts; it does not create continuous 15-second vibration. See Apple's guide.

Detection limits

The timer covers the entire app. It cannot distinguish YouTube Shorts from regular videos or Instagram Reels from messages, read other apps' screens, or detect individual swipes.
